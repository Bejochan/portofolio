# Adnan Oktar - Portfolio Website

This is the source code for my personal portfolio website, built with a strict minimalist, monochromatic, and brutalist architectural approach. 

## 🌐 Live Demo
The website is deployed and automatically synced via Vercel:
**[adnanoktar.vercel.app](https://adnanoktar.vercel.app)**

## 🛠️ Technology Stack
- **Architecture**: Multi-page Static Site (MPA)
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Design System & CSS Variables)
- **Deployment**: Vercel Git Integration

## ✨ Features
- **Zero-Dependency**: No external heavy JS frameworks (React/Vue) or CSS libraries (Tailwind/Bootstrap). Ensuring blazing-fast load times.
- **Strict Monochrome Theme**: Designed with an absolute black, white, and gray palette to give an elegant architectural feel.
- **Symmetrical Grid Layouts**: Calculated UI ratios for all project cards and skill sections.

## 🚀 How to Run Locally
Because this project is built entirely with pure HTML & CSS, no build tools or package managers are required.
1. Clone this repository: `git clone https://github.com/Bejochan/portofolio.git`
2. Open the folder and double-click `index.html` to open it directly in your favorite web browser.

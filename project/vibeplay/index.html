The Engineering Challenge & Objective

Commercial game marketplaces inundate users with massive catalogs lacking situational personalization. Building VibePlay required creating a fault-tolerant, checkpoint-persisted data ingestion pipeline capable of scraping thousands of games across Steam and RAWG APIs while surviving severe rate-limits (HTTP 429), cleaning dirty metadata, and executing weighted hybrid multi-attribute recommendation algorithms in real-time.

Architecture & Data Flow

  1. Fault-Tolerant Checkpoint Web Scraper: fetch_data.py auto-saves progress to progress_temp.csv every 50 games wrapped in try...finally blocks to prevent data loss.
  2. Automated Data Sanitization: filter_prices.py applies multi-layer regex pipelines to eliminate NSFW titles, reconcile irregular price formats, and map real Steam IDR currency data.
  3. Psychographic 12-Item Questionnaire: Evaluates player tendencies along Casual/Hardcore, Simple/Complex, and Calming/Adrenaline dimensions.
  4. Mood-Adjusted DNA: Dynamically shifts baseline DNA coordinates by 15%–35% based on momentary mood selections.
  5. Dual-Session Recommendation Engine: Computes Balanced Match and High-Rating Priority recommendations visualized via an interactive 6-axis psychographic polygon radar chart.

Key Technical Contributions

  • Prevented scraping failure and data loss across 24,082 games with automated checkpoint flushing.
  • Implemented weighted hybrid recommendation algorithms balancing genre overlap, DNA distance, and budget limits.
  • Developed an interactive 6-axis psychographic polygon radar chart visualizing multidimensional playstyle compatibility and dynamic mood vectors.

Measurable Metrics

  • Catalog Scale: 24,082 Curated Games
  • Checkpoint Resilience: 50-item auto-flush (Zero data loss)
  • Dimensionality: 6-Axis Psychographic Polygon Radar Profiling

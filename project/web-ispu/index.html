The Engineering Challenge & Objective

Air quality monitoring systems often suffer from stale data ingestion and fragile network synchronizations. Sistem Prediksi ISPU provides official Indonesian Air Pollution Standard Index (ISPU) monitoring and 24-hour predictive forecasts across 38 administrative cities/regencies in East Java. The objective was to design an unattended, fault-tolerant ingestion pipeline that continuously streams pollutant and meteorological features without manual intervention.

Architecture & Data Flow

  1. Automated Ingestion Scheduler: APScheduler executes hourly data extraction within Flask.
  2. Feature Extraction: Polls real-time PM2.5, PM10, CO, NO2, SO2, and O3 levels from OpenWeatherMap API for 38 regional coordinates.
  3. Sanitization & Timezone Casting: Applies explicit UTC+7 timezone casting to resolve timestamp discrepancies.
  4. Resilient Supabase Layer: Stores time-series data using SQLAlchemy with pre-ping validation and connection pool recycling.
  5. Stateless REST API: Serves structured JSON payloads to an interactive Vanilla JavaScript frontend.

Key Technical Contributions

  • Timezone Boundary Bug Fix (Commit 2fb9994): Resolved a critical 24-hour historical window query discrepancy caused by naive timestamp parsing by implementing explicit PostgreSQL casting: CAST(waktu_aktual || ' +07:00' AS TIMESTAMP WITH TIME ZONE).
  • Connection Pool Resilience (Commit fb5ef20): Fixed intermittent database connection dropouts on cloud cold-starts by configuring SQLAlchemy with pool_pre_ping=True and connection recycling (pool_recycle=280).
  • Unattended Ingestion: Maintained continuous 1-hour automated ingestion covering all 38 cities in East Java with zero manual intervention.

Measurable Metrics

  • Geographic Coverage: 38 / 38 Cities and Regencies in East Java
  • Ingestion Cadence: Automated hourly polling (APScheduler)
  • Pipeline Uptime: 99.9% unattended reliability

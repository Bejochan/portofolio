The Engineering Challenge & Objective

Secondary collectible marketplaces require instant and highly accurate visual identification across arbitrary camera angles, variable lighting, and physical card degradation. Standard image classifiers fail when dealing with thousands of subtle holographic variations, while direct pairwise pixel comparison introduces prohibitive latency for real-time user experiences. The engineering objective was to construct a high-throughput retrieval pipeline capable of indexing 20,617 card variations with sub-20ms GPU latency, recovering degraded input imagery, and generating probabilistic multi-step time-series price forecasts.

Architecture & Data Flow

  1. Client Compression & Camera HUD: Canvas 1280px compresses smartphone uploads by 97% (150-300 KB). Live Scanner HUD executes multithreaded asynchronous workers with 7-frame consensus smoothing at 30+ FPS.
  2. Adaptive Degradation Preprocessing: Neutralizes degraded real-world photos via Gamma LUT (gamma 0.75 for low-light, 1.6 for overexposure), directional 5x5 deblurring filter, inner artwork contour rejection, and 4-way auto-orientation (0°, 90°, 180°, 270°).
  3. Dense Vector Search (CLIP + FAISS): Extracts 512-dimensional embeddings using OpenAI CLIP (ViT-B/32) and executes FAISS IndexFlatIP cosine similarity across 20,617 cards in < 1 ms (~18 ms GPU latency on RTX 2050).
  4. In-Memory Top-8 ORB Re-Ranking: Evaluates Top-8 candidates with in-memory descriptor caching (up to 250 items), saving >1,000 ms disk I/O while achieving 93.8% real-world accuracy, calibrated with Sigmoid margin scaling (tau = 0.03).
  5. Model 3 Probabilistic Forecasting: Amazon Chronos-Bolt Mini foundation model generates 7-day multi-step quantile price curves (P10, P50, P90) in 25-35 ms GPU latency, formulating prescriptive BUY, HOLD, or SELL trading signals.
  6. Automated Ingestion & RAM Pricing: A daily GitHub Actions cron updates Supabase PostgreSQL pricing, while zero-latency in-memory lookups (0.00 ms) in RAM serve requests instantaneously.

Key Technical Contributions

  • Sub-20ms Vector Retrieval & 30+ FPS Live HUD: Indexed 20,617 card representations via OpenAI CLIP (ViT-B/32) and FAISS IndexFlatIP, transitioning inference to local CUDA GPU acceleration (~18 ms on RTX 2050, ~83 ms on CPU) with multithreaded worker decoupling.
  • Adaptive Preprocessing & In-Memory ORB Caching: Built gamma LUTs and directional deblurring filters that recover degraded real-world captures, paired with Top-8 hybrid ORB caching achieving 93.8% empirical accuracy without continuous disk I/O.
  • Industrial Time-Series Forecasting (Chronos-Bolt): Integrated Amazon Chronos-Bolt Mini for zero-shot 7-day probabilistic price ribbon projections (P10/P50/P90) in 25-35 ms GPU latency, delivering prescriptive trading tunnels.
  • Full-Stack Production System: Architected FastAPI v3.1.0 backend with 14 REST endpoints, client-side 1280px canvas compression, zero-latency in-memory pricing lookup (0.00 ms), and unattended GitHub Actions cron workflows.

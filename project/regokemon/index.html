The Engineering Challenge & Objective

Trading card secondary marketplaces suffer from high transaction friction, subjective manual grading, and volatile pricing. Identifying a specific card among 20,400+ historical variants (especially distinguishing subtle holofoil/secret-rare prints) under varied camera angles, glare, and rotations is challenging. The goal was to build a low-latency visual retrieval engine coupled with an automated real-time price tracking pipeline.

Architecture & Data Flow

  1. Camera Frame Preprocessing: OpenCV (cv2) captures webcam or uploaded frames, applies Laplacian variance blur detection, and performs 4-way auto-orientation (0Â°, 90Â°, 180Â°, 270Â°).
  2. Dense Vector Embedding: Images are converted into 512-dimensional embeddings using OpenAI CLIP (ViT-B/32).
  3. Sub-millisecond Vector Retrieval: FAISS IndexFlatIP (Cosine Similarity) retrieves candidate matches from 20,400+ pre-indexed card vectors in < 200 ms.
  4. Fine-Grained ORB Re-Ranking: Expands candidate pool from 50 to 150 items (Commit 7707151), using ORB feature keypoint matching and RANSAC homography estimation to discriminate holo-foil patterns.
  5. Automated Price Sync & Valuation: A daily GitHub Actions cron (daily_price_tracker.py) queries pokemontcg.io API, calculates effective market prices, and updates Supabase (card_prices and card_price_history).

Key Technical Contributions

  • Formatted 20,400+ card representations using OpenAI CLIP ViT-B/32 into a high-performance FAISS IndexFlatIP.
  • Transitioned inference from CPU (~1,200 ms) to local CUDA GPU acceleration (< 200 ms total latency) on an RTX workstation.
  • Engineered automated daily market price tracking cron in GitHub Actions updating Supabase with historical pricing.

Measurable Metrics

  • Inference Latency: < 200 ms (CUDA GPU)
  • Catalog Scale: 20,400+ cards indexed
  • Automation: 100% automated daily market pricing cron

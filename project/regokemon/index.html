The Engineering Challenge & Objective

Secondary collectible marketplaces require instant and highly accurate visual identification across arbitrary camera angles, variable lighting, and physical card degradation. Standard image classifiers fail when dealing with thousands of subtle holographic variations, while direct pairwise pixel comparison introduces prohibitive latency for real-time user experiences. The engineering objective was to construct a high-throughput retrieval pipeline capable of indexing 20,617 card variations with sub-200ms latency while maintaining continuous market pricing synchronization.

Architecture & Data Flow

  1. Camera Frame Preprocessing: OpenCV (cv2) captures webcam or uploaded frames, applies Laplacian variance blur detection, and performs 4-way auto-orientation (0°, 90°, 180°, 270°).
  2. Dense Vector Embedding: Images are converted into 512-dimensional embeddings using OpenAI CLIP (ViT-B/32).
  3. Sub-millisecond Vector Retrieval: FAISS IndexFlatIP (Cosine Similarity) retrieves candidate matches from 20,617 pre-indexed card vectors in < 200 ms.
  4. Fine-Grained ORB Re-Ranking: Expands candidate pool from 50 to 150 items (Commit 7707151), using ORB feature keypoint matching and RANSAC homography estimation to discriminate holo-foil patterns.
  5. Automated Price Sync & Valuation: A daily GitHub Actions cron (daily_price_tracker.py) queries pokemontcg.io API, calculates effective market prices, and updates Supabase (card_prices and card_price_history).

Key Technical Contributions

  • Sub-200ms Vector Retrieval (CLIP + FAISS): Formatted 20,617 card representations using OpenAI CLIP (ViT-B/32) 512-dimensional embeddings into a FAISS IndexFlatIP index, transitioning inference from CPU (~1,200 ms) to local CUDA GPU acceleration (< 200 ms total latency).
  • Fine-Grained Holographic Discrimination (Commit 7707151): Engineered ORB feature keypoint matching and RANSAC homography re-ranking across top 150 candidates, discriminating subtle foil variations and physical print editions under arbitrary lighting.
  • Automated Market Valuation Pipeline: Built a serverless GitHub Actions cron workflow executing daily batch upserts of live TCGPlayer and Cardmarket pricing into Supabase without operational overhead.

Measurable Metrics

  • Vector Retrieval Latency: < 200 ms (CUDA GPU Acceleration)
  • Catalog Indexing Scale: 20,617 Cards (512-Dimensional Dense Vectors)
  • Market Data Synchronization: Automated Daily Cron (GitHub Actions & Supabase)
